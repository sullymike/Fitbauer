# Fitbauer v5.1.2

*[🇪🇸 Notas en español](https://github.com/sullymike/Fitbauer/blob/main/RELEASE_NOTES_v5.1.2_ES.md)*

NORMOS compatibility goes into the interface, Ising relaxation is now validated
against the NORMOS executable, and several fixes.

---

## NORMOS conventions in the interface

New submenu **Fit ▸ Advanced fit options ▸ Conventions (NORMOS compatibility)**,
with three choices. The first option of each is Fitbauer's default:

- **Sextet line pattern**: published α-Fe positions, or positions derived from
  the nuclear moments as NORMOS does. On the same spectrum the field differs by
  about 0.01 T at 33 T.
- **Intensity ratios**: by depth, or by area as NORMOS's D13/D23. They only
  differ when the line widths Γ2/Γ3 differ from Γ1.
- **Relaxation with unequal populations**: Blume's model with detailed
  balance, or the NORMOS rule (see below).

They apply everywhere at once: live simulation, discrete and distribution fits,
bootstrap and profile likelihood. They are saved in the session and remembered
as a preference, and the status panel warns when one differs from the default.
A fit of α-Fe in the interface with either pattern gives the same result as the
command line.

## Relaxation: own model, validated against NORMOS

- The two-state relaxation with unequal populations is now Fitbauer's own
  implementation of Blume's stochastic model (Phys. Rev. 174, 351, 1968).
  **Results change for polarization P > 0**; with P ≤ 0 nothing changes.
- A new probe of the NORMOS-SITE executable shows that, with equal populations,
  Fitbauer reproduces NORMOS's Ising relaxation to 10⁻⁵ of the peak over six
  decades of the relaxation rate. NORMOS's `OME` (MHz) is twice Fitbauer's
  exchange rate.
- With unequal populations NORMOS follows a rule that does not satisfy detailed
  balance. It is available as the optional **NORMOS convention**, which
  reproduces the executable to 4·10⁻⁵, from the menu above or with
  `--relax-convention normos` on the command line. The default remains the
  physical model.

## Validation against NORMOS, regenerated

The validation bench against NORMOS (more than 400 spectra generated by NORMOS
and fitted by Fitbauer) has been regenerated with the current version and
reproduces the published figures. It now runs with a single script,
`validacion/generador/banco_completo.sh`.

## Fixes

- Older sessions fitted in discrete mode opened in distribution mode. This
  affected the example sessions the README recommends; they have also been
  regenerated with the current format.
- Bootstrap and profile-likelihood replicas ignored the area intensity
  convention and were refitted with the depth one.
- The autosave timer kept running after closing the window and could rewrite
  the recovery file that a clean exit had just removed.
